Manual de Integração

Siga estes passos para conectar sua aplicação à InfoAPI em minutos.

Confira no tutorial em vídeo como realizar o fluxo completo de autenticação e a primeira chamada à API de forma correta:

1

Autenticação (Obter Token)

Toda comunicação é protegida. Primeiro, você deve trocar suas credenciais por um token de acesso.

POST /api/v1/auth/login
Authorization: Basic [USUARIO:SENHA em Base64]

O retorno conterá um access_token (válido por 1h) e um refresh_token.

2

Realizar Requisições

Com o token em mãos, adicione-o ao cabeçalho de todas as chamadas seguintes.

GET /api/v1/products
Authorization: Bearer [SEU_ACCESS_TOKEN]
3

Renovação Automática (Refresh)

Para evitar que sua integração pare de funcionar quando o token expirar, use o refresh_token.

Dica: Não peça para o usuário logar de novo. Use o refresh token para pegar um novo acesso silenciosamente.
POST /api/v1/auth/refresh
Body: { "refresh_token": "..." }

Manual para sua IA (Claude, ChatGPT, etc)

Copie o prompt abaixo e cole na sua IA favorita para gerar o código de integração instantaneamente:

"Preciso de um script em Python (ou sua linguagem) para integrar com a InfoAPI. 1. O login é em /api/v1/auth/login usando Basic Auth. 2. Salve o access_token e o refresh_token. 3. Faça um GET em /api/v1/products com o token. 4. Se receber erro 401, use o refresh_token em /api/v1/auth/refresh para renovar o acesso e tente novamente."

                                 Guia de Integração: Formato do Payload & Validação da Chave Secreta
                            

                            

                                Entenda a estrutura dos eventos recebidos e como utilizar sua chave whsec_... para validar a autenticidade criptográfica com HMAC-SHA256.
                            

                        

                        
                             HMAC-SHA256
                        
                    


                    
                    

                        

                             1. Cabeçalhos HTTP Enviados em Cada Notificação
                        

                        

                            

                                
                                    

                                        Cabeçalho HTTP
                                        Exemplo de Valor
                                        Descrição e Finalidade
                                    

                                
                                
                                    

                                        X-Info-Signature
                                        t=1763380200,v1=9f8a3c...
                                        Assinatura digital calculada via HMAC-SHA256 com sua Chave Secreta. Use para comprovar que o disparo partiu da InfoBrasil.
                                    

                                    

                                        X-Info-Event
                                        orders.created
                                        Nome do evento disparado. Permite ao seu roteador filtrar requisições antes mesmo de processar o JSON.
                                    

                                    

                                        X-Info-Delivery-Id
                                        cm3x89a... (UUID)
                                        Identificador exclusivo desta tentativa de entrega. Dica de Idempotência: guarde esse ID para descartar mensagens repetidas.
                                    

                                    

                                        Content-Type
                                        application/json
                                        Todos os payloads são entregues em JSON codificado em UTF-8.
                                    

                                
                            

                        

                    


                    
                    

                        

                             2. Estrutura do Payload JSON (Corpo da Requisição POST)
                        

                        

                            

                                
{
  "id": "cm3x98a120000abcde1234567",
  "event": "orders.created",
  "timestamp": 1763380200,
  "data": {
    "id": 10452,
    "storeId": 1,
    "customer": "Supermercado Exemplo",
    "total": 450.90,
    "status": "APROVADO",
    "createdAt": "2026-11-17T12:00:00.000Z"
  }
}

                            

                            

                                
id: UUID único da notificação para deduplicação no seu banco/filas.

                                
event: Nome qualificado do evento assinado (ex: orders.created, products.stock_changed).

                                
timestamp: Epoch Unix (em segundos) do disparo. Útil para rejeitar requisições atrasadas.

                                
data: Dados detalhados da entidade gerada no ERP InfoBrasil.

                            

                        

                    


                    
                    

                        

                             3. Por Que a Chave Secreta (`whsec_...`) Não Vem no Payload?
                        

                        

                            

                                A chave whsec_... é um Segredo Compartilhado (*Shared Secret*), exatamente como na Stripe e no GitHub. Ela NUNCA trafega pela rede. Se ela fosse enviada em texto puro, qualquer interceptador na internet poderia capturá-la e forjar pedidos falsos para o seu sistema.
                            

                            

                                Como a InfoBrasil assina:

                                Ao enviar o webhook, nossos servidores pegam o timestamp t e o corpo bruto JSON rawBody e calculam:
                                

                                
                                    hash = HMAC-SHA256(t + "." + rawBody, suaChaveSecreta)
                                
                            

                            

                                O resultado é enviado no header X-Info-Signature: t=1763380200,v1=9f8a3c....

                                No seu integrador, você guarda a chave no seu .env, recalcula o hash sobre a mensagem recebida e compara com v1. Se forem idênticos, a mensagem é 100% autêntica e inalterada!
                            

                        

                    


                    
                    

                        

                            

                                 4. Código Pronto de Validação para Copiar
                            

                            

                                
                                
                                
                            

                        


                        
                        

                            
const express = require('express');
const crypto = require('crypto');
const app = express();

// IMPORTANTE: Utilize express.raw para preservar os bytes exatos antes do JSON.parse
app.post('/webhook', express.raw({ type: 'application/json' }), (req, res) => {
  const signatureHeader = req.headers['x-info-signature'];
  const secretKey = process.env.WEBHOOK_SECRET; // Sua chave whsec_...

  if (!signatureHeader || !secretKey) {
    return res.status(401).send('Assinatura ausente ou chave não configurada');
  }

  // 1. Extrai timestamp (t) e hash da assinatura (v1)
  const parts = Object.fromEntries(signatureHeader.split(',').map(kv => kv.split('=')));
  const { t, v1 } = parts;

  // 2. Proteção contra Replay Attack (tolerância recomendada: 5 minutos)
  const now = Math.floor(Date.now() / 1000);
  if (Math.abs(now - parseInt(t, 10)) > 300) {
    return res.status(400).send('Timestamp expirado (> 5 min)');
  }

  // 3. Recalcula o HMAC-SHA256
  const rawBody = req.body.toString('utf8');
  const expectedHash = crypto
    .createHmac('sha256', secretKey)
    .update(`${t}.${rawBody}`)
    .digest('hex');

  // 4. Comparação em tempo constante (evita Timing Attacks)
  const isValid = crypto.timingSafeEqual(
    Buffer.from(v1, 'hex'),
    Buffer.from(expectedHash, 'hex')
  );

  if (!isValid) {
    return res.status(401).send('Assinatura HMAC inválida!');
  }

  // Payload autêntico! Prossiga com as ações no seu sistema:
  const payload = JSON.parse(rawBody);
  console.log(`Evento autêntico recebido: ${payload.event}`, payload.data);

  return res.status(200).json({ received: true });
});

                        


                        
                        

                            
from fastapi import FastAPI, Request, HTTPException, Header
import hmac
import hashlib
import time
import os

app = FastAPI()
WEBHOOK_SECRET = os.getenv("WEBHOOK_SECRET") # Sua chave whsec_...

@app.post("/webhook")
async def receive_webhook(request: Request, x_info_signature: str = Header(None)):
    if not x_info_signature or not WEBHOOK_SECRET:
        raise HTTPException(status_code=401, detail="Assinatura ausente")

    # 1. Extrai timestamp (t) e hash (v1)
    parts = dict(kv.split("=") for kv in x_info_signature.split(","))
    t = parts.get("t")
    v1 = parts.get("v1")

    # 2. Proteção contra Replay Attack (5 minutos)
    if abs(int(time.time()) - int(t)) > 300:
        raise HTTPException(status_code=400, detail="Notificação expirada")

    # 3. Recalcula HMAC-SHA256 sobre o raw body
    raw_body = await request.body()
    signature_payload = f"{t}.".encode("utf-8") + raw_body
    expected_hash = hmac.new(
        WEBHOOK_SECRET.encode("utf-8"),
        signature_payload,
        hashlib.sha256
    ).hexdigest()

    # 4. Comparação segura de tempo constante
    if not hmac.compare_digest(v1, expected_hash):
        raise HTTPException(status_code=401, detail="Assinatura HMAC inválida")

    # Payload autêntico!
    event_data = await request.json()
    print(f"Evento recebido: {event_data['event']}")
    return {"received": True}

O JWT é um padrão para
                        transmissão segura de informações. Na nossa API, ele é o "crachá" que você usa após o login.

                    

                        Stateless (Sem Sessão)

                        Cabeçalho Authorization

 Autenticação Basic

                    
Método usado
                        exclusivamente na rota de Login para obter seu token JWT inicial. O cabeçalho é composto pela
                        string usuario:senha codificada em Base64.


                    

                        

                            

                                Exemplo em JavaScript:

                            

                                
const auth = btoa('user:pass');
console.log('Basic ' + auth);

                                
                            

                        

                        

                            
Exemplo
                                em Python:

                            

                                
import base64
auth = base64.b64encode(b'user:pass').decode()
print(f'Basic {auth}')
